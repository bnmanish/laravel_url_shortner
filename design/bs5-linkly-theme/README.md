# Linkly — Bootstrap 5 URL Shortener Theme

A responsive multi-page URL shortener dashboard theme inspired by modern link-management products.

## Pages
- `index.html` — landing page
- `links.html` — link management dashboard
- `analytics.html` — analytics dashboard
- `pricing.html` — pricing
- `login.html` — login
- `signup.html` — signup
- `404.html` — error page

## Stack
- Bootstrap 5.3 CDN
- Bootstrap Icons CDN
- Vanilla JavaScript
- Custom CSS
- No build step required

Open `index.html` directly in a browser, or serve the folder with any static web server.
